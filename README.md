# Full-Stack Data Science Projects

A collection of notebooks and small applications exploring data analysis, visualization, language models, and image generation.

## Projects

1. **Heart disease analysis** — exploratory analysis and visualization using the heart disease dataset.
2. **FIFA data exploration** — Seaborn-based exploration of FIFA player data.
3. **LLM-assisted EDA** — a Gradio project using Mistral to help automate exploratory analysis.
4. **Sales analysis** — a Streamlit application and notebook applying statistical analysis to sales data.
5. **Text-to-image generation** — a Stable Diffusion 2.1 notebook.

Project folders contain the corresponding notebooks and datasets. Start with the notebook or `app.py` in the project folder you want to explore.

## Requirements

Dependencies vary by project. Review the imports in the selected notebook or app and install the corresponding packages. Some projects require model access or more compute than a basic notebook runtime.

## Repository layout

Each `Project - N` directory is an independent experiment; there is no single shared application entry point.
